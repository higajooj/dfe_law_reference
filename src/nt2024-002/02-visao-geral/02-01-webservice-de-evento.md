# 2.1. Webservice de Evento

Para o modelo 55 (NF-e), a Sefaz Virtual do Rio Grande do Sul (SVRS) disponibiliza o WebService de eventos que será utilizado por contribuintes de todas as unidades federadas para autorização do ECONF, no endereço do Webservice de Eventos da SVRS:

https://nfe.svrs.rs.gov.br/ws/recepcaoevento/recepcaoevento4.asmx.

Para o modelo 65 (NFC-e), os Contribuintes deverão usar o Webservice de Eventos próprio da UF (mesma URL utilizada para o Evento de Cancelamento).
