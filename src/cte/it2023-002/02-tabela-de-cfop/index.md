# 02. Tabela de CFOP

A Tabela de CFOP relaciona os Códigos Fiscais de Operações e Prestações vigentes, definidos pelo Convênio SINIEF s/nº, de 15 de dezembro de 1970, e suas alterações posteriores, associando a cada código um conjunto de indicadores utilizados pelos Serviços de Autorização na validação dos documentos fiscais eletrônicos.

| Coluna | Descrição | Situação |
|---|---|---|
| CFOP | Código Fiscal de Operações e Prestações, com 4 dígitos. | Inalterada |
| Início de vigência | Data a partir da qual o código pode ser utilizado. | Inalterada |
| Fim de vigência | Data a partir da qual o código deixa de ser aceito (em branco, quando vigente). | Inalterada |
| indNFe | Indica se o CFOP é permitido na NF-e / NFC-e. | Inalterada |
| indComunica | Indica se o CFOP é permitido em operação de prestação de serviço de comunicação. | Inalterada |
| indTransp | Indica se o CFOP é permitido em operação de prestação de serviço de transporte. | Inalterada |
| indDevol | Indica se o CFOP corresponde a operação de devolução. | Inalterada |
| indRetor | Indica se o CFOP corresponde a operação de retorno. | Inalterada |
| indAnula | Indica se o CFOP corresponde a operação de anulação de valor. | Inalterada |
| indRemes | Indica se o CFOP corresponde a operação de remessa. | Inalterada |
| indComb | Indica se o CFOP é permitido em operação com combustível ou lubrificante. | Inalterada |
| indExcIBSCBS | Indica se o CFOP é permitido na NF-e (modelo 55) emitida por contribuinte exclusivo do IBS/CBS. | Nova |
| <mark>Título</mark> | <mark>Denominação do CFOP, conforme o Anexo II do Convênio SINIEF s/nº, de 15/12/1970.</mark> | <mark>Nova</mark> |
| <mark>Descrição</mark> | <mark>Nota explicativa do CFOP, conforme o Anexo II do Convênio SINIEF s/nº, de 15/12/1970.</mark> | <mark>Nova</mark> |
