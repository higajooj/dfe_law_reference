# 14. WS disponíveis

Os endereços dos Web Services disponíveis podem ser obtidos no sítio nacional do projeto no endereço [http://www.cte.fazenda.gov.br](http://www.cte.fazenda.gov.br) ou no portal da SVRS em [https://dfe-portal.svrs.rs.gov.br/Cte](https://dfe-portal.svrs.rs.gov.br/Cte).

**Obtenção do WSDL:**

A documentação do WSDL pode ser obtida na internet acessando o endereço do Web Service desejado.

Exemplificando, para obter o WSDL de cada um dos Web Service acione o navegador Web (Internet Explorer, por exemplo) e digite o endereço desejado seguido do literal ‘?WSDL’.
