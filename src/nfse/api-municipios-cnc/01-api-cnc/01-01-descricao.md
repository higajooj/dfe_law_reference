# 1.1. Descrição

Serviço para atender dois objetivos: a manutenção e a distribuição do CNC NFS-e.

Para o serviço de distribuição do CNC NFSe será utilizada API que terá como identificador o NSU Cadastro ou NSU Movimento e poderá utilizar também filtros adicionais como CPF/CNPJ, código do município e/ou inscrição municipal.
