# 6.3 Quem precisa se manifestar?

- **Empresas e Frotistas (Pessoas Jurídicas):** Devem realizar a manifestação de todas as passagens para apropriar os créditos fiscais decorrentes do transporte.
- **Pessoas Físicas e MEI:** A manifestação é opcional, servindo para organização pessoal e comprovação da despesa.
