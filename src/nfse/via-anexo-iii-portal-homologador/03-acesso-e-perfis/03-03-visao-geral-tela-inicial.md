# 3.3 Visão geral da tela inicial

Ao acessar a aplicação, o usuário será direcionado para a Tela Inicial onde o layout pode variar de acordo com o perfil de acesso do usuário, exibindo somente as funcionalidades pertinentes para cada perfil. Esta tela reúne as principais informações para facilitar a navegação e o acompanhamento das atividades.
