# 3.4 Perfil de acesso

O Perfil de acesso disponibilizado deve ser usando conforme a função do usuário.

**Concessionária**

Utilizado para Emitir, Cancelar, Substituir e Consultar NFS-e Via e alíquota efetiva do trecho.

<!-- p.05 -->

Ao entrar na aplicação com o CNPJ selecionado, ele trará todos os contratos/trechos que já estejam cadastrados para esse CNPJ no Portal da Concessionaria.

OBS.: Caso não tinha nenhum contrato cadastrado, não será possível gerar NFS-e via, pois a aplicação utiliza os dados cadastrados no portal como praças, trechos e alíquotas.

**Município**

Utilizado para Consultar NFS-e Via emitidas por NSU, alíquotas cujo o município esteja cadastro no trecho.

(Não disponibilizado nessa versão)

**Comitê Gestor**

Utilizado para Consultar todas as NFS-e Via emitidas, todas as alíquotas de um determinado trecho (MAN).
