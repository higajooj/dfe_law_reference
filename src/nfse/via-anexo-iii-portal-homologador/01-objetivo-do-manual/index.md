# 1 Objetivo do Manual

Este manual tem como objetivo orientar os usuários na utilização da aplicação desenvolvida para facilitar o processo de homologação de API´s utilizadas na integração entre Concessionárias, Comitê Gestor, RFB e Ambiente nacional.

O documento fornece instruções sobre o acesso, a navegação e utilização das funcionalidades da aplicação.

Obs.: Para orientações de como usar as API´s da NFS-e Via, utilize:

- Concessionária: Anexo II_Guia para utilização das API´s
- Municípios: Manual dos Municípios
- Comitê Gestor: Manual do Comitê Gestor

Obs.: Para orientações de como cadastrar um contrato de uma concessionária, utilize:

- Concessionária: Anexo I_Guia parametrização do Portal das Concessionáris NFS-e Via
