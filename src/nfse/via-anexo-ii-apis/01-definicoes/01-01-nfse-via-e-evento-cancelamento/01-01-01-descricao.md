# 1.1.1 Descrição

As informações serão fornecidas pelas Concessionárias por meio de arquivo(s) XML. O XML de NFS-e Via e seus Eventos deverão ser enviado através de uma API REST (modo assíncrono) ao Ambiente Nacional da NFS-e Via.

O processamento dos documentos será executado de forma assíncrona, recebidos via API REST. Além disso, o sistema dispõe de serviços específicos para consultas, permitindo obter informações sobre o processamento dos arquivos eletrônicos enviados pelas Concessionárias e o resultado da sua validação.
