# 1.4.1. Descrição

Serviço cujo objetivo principal é recuperar a chave de acesso da NFS-e a partir de uma consulta pelo identificador da DPS (Código IBGE do Município Emissor (7), Tipo de Inscrição (1), Inscrição Federal (14 - CPF completar com 000 à esquerda), Série DPS (5), Núm. DPS (15). No entanto, por questões de sigilo fiscal, a chave de acesso será informada somente se a identificação do usuário do certificado digital da conexão solicitante for um ator (Prestador, Tomador ou Intermediário) que consta na NFS-e gerada a partir da DPS consultada.
